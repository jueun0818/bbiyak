# 🐥 삐약궁합

이름·사주팔자·별자리·혈액형·MBTI로 보는 재미용 궁합 웹앱. 결과를 인스타 스토리용 이미지(1080×1920)로 저장할 수 있습니다.

의존성 없는 정적 사이트이고, 화면·계산 로직·효과음(Web Audio)까지 `index.html` 한 파일에 들어 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI · 궁합 계산 · 스토리 이미지 생성 · 배경음악) |
| `manifest.webmanifest` | PWA 매니페스트 (홈 화면 설치 정보, 바로가기 3개) |
| `sw.js` | 서비스 워커 (오프라인 실행, 업데이트 안내) |
| `icons/` | 앱 아이콘 (`any` / `maskable` / iOS `apple-touch-icon`) |

## PWA

- 홈 화면에 설치해 주소창 없이 앱처럼 실행됩니다. 안드로이드·데스크톱 크롬은 설치 배너, iOS 사파리는 '홈 화면에 추가' 안내 시트가 뜹니다.
- 한 번 열어두면 **오프라인에서도** 동작합니다. 페이지는 네트워크 우선(새 버전 즉시 반영), 정적 파일은 캐시 우선 + 백그라운드 갱신 전략입니다.
- 홈 화면 아이콘을 길게 누르면 종합 궁합 / 사주 궁합 / MBTI 궁합으로 바로 들어가는 바로가기가 나옵니다.

> 서비스 워커와 앱 설치는 **HTTPS 또는 localhost**에서만 동작합니다. `index.html`을 파일로 직접 열면(`file://`) PWA 기능은 빠진 상태로 보입니다.

## 로컬 실행

정적 파일이라 아무 정적 서버로도 됩니다.

```bash
python -m http.server 8940
```

그다음 <http://localhost:8940> 접속.

## 배포

이 저장소를 GitHub Pages로 켜면(Settings → Pages → Branch: `main` / `/root`) `https://<사용자>.github.io/bbiyak/` 에서 바로 설치할 수 있습니다. 모든 경로가 상대 경로라 하위 경로 배포에서도 그대로 동작합니다.

## 수정할 때

`index.html`이나 아이콘을 고치면 `sw.js`의 `VERSION` 상수를 올려주세요. 그래야 이미 설치한 기기에 "새 버전이 준비됐어요" 안내가 뜨고 캐시가 교체됩니다.

## 면책

모든 결과는 재미용이며 과학적·통계적 근거가 없습니다.
